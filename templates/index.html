System Capabilities

What Waqqas does at every layer

Full capability list →

Five-class threat classification

Classifies every connection record as Normal, Denial of Service, Reconnaissance/Scanning, Privilege Escalation, or Credential/Access Abuse. Each result carries a confidence score that drives downstream routing — high-confidence threats escalate automatically.

Confidence-gated unknown escalation

When ensemble confidence falls below the threshold, the event is routed as "Unknown Suspicious Behavior" instead of being forced into an unreliable category. Uncertain events surface for analyst review — never silently dismissed.

Source IP-linked response controls

Every classified record retains its source IP. Critical high-confidence threats trigger automatic blocking. Analysts can block or unblock any source directly from the dashboard, with every action logged in a timestamped audit trail.

Feedback with safe label normalization

Analyst corrections are resolved to canonical labels before storage, preventing inconsistent inputs from corrupting future retraining pipelines. Ambiguous entries are rejected with an explicit warning.

Detection Lifecycle

From upload to decision in four steps

1 — Upload structured connection records

Accepts CSV traffic files in the platform’s expected layout, with optional source_ip for investigation and blocking. Validation and normalization run automatically — no manual preprocessing required.

2 — Ensemble inference with confidence scoring

The Soft Voting Ensemble runs inference on each row, returning a predicted class, confidence score, and risk tier — persisted to the database immediately for every upload session.

3 — Alert-first threat surfacing

Dangerous and unknown events trigger a visual alert immediately after upload, showing attack type, source IP, confidence, and risk level with direct Block / Ignore / View controls.

4 — Feedback capture and model refresh

Analyst feedback is recorded per prediction with optional corrected labels. Corrections are normalized before storage. A background model refresh can be triggered anytime without interrupting live classification.
